Opens a TCP connection to ``host`` (a host name, an IPv4 or IPv6 literal, or ``localhost``) on ``port``, trying each address the name resolves to in turn. Blocks until the peer accepts, refuses, or ``timeout_ms`` milliseconds pass across every address; on success the socket is non-blocking and ``onConnect`` has run. Returns false, with ``onError`` called, when the host does not resolve, every address refuses or times out, or the client is already connected.
